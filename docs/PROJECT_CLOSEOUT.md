# Completed public project

The maintained release presents the final grouped context evaluation, original
external-score record, numerical MRI input/pooling/scoring contracts, a fitted
synthetic CPU control, and the interactive engineering demonstration.

Superseded feature campaigns, teacher-label experiments, private-runner scaffolding,
intermediate notebooks, vendor plots and one-time cloud/operator scripts are retired
from the current tree. The original final aggregate report, necessary comparison
controls, limitations and source attribution remain. Git history is not rewritten.

Public reproduction does not depend on the removed AWS spaces. Full private model
reconstruction would additionally require the original licensed images, model
artifacts and tuned recipe; those are not distributed. Neither a synthetic example
nor verified output identity substitutes for clinical validation.
