# AWS research frontier

## Research boundary

AWS/SageMaker is the canonical environment for MRI data, feature extraction, training, grouped validation, inference, checkpointing, diagnostics, and experiment state.

GitHub is the curated public engineering layer. Private MRI, identifiers, row-level predictions, checkpoints, recovery handles, cloud paths, and competition-specific inference stay outside Git history.

## Canonical validation contract

The established research boundary includes:

- **4,407 studies** in the canonical exact-window cache;
- **69.14 GiB** cache size;
- **4,349 grouped non-gold rows**;
- **58 fully labeled audit rows**;
- **59 scanner groups**;
- fold sizes **870 / 870 / 870 / 870 / 869**;
- **zero scanner groups crossing folds**;
- **zero audit rows used by the grouped optimizer**.

A lineage audit later established that the 58 fully labeled rows participated in historical checkpoint selection for recovered components. They are not presented as untouched confirmation.

## Complementary residual modeling

A narrow residual route remains a retained positive development challenger on the grouped boundary.

The public lesson is methodological:

- identify residual headroom by finding;
- require matched controls;
- protect unaffected targets;
- retain valid small positive aggregate evidence;
- use uncertainty and provenance for promotion decisions.

Exact blend weights, row-level predictions, and private checkpoint identities remain private.

## Parent-first strategy

The central strategy is:

> **freeze the verified parent as the control, reconstruct its trained branches faithfully, and introduce one genuinely new capability at a time.**

The reconstructed parent now has verified engineering execution for:

- native multi-member DINO inference;
- RadImageNet-family heads/layouts;
- all five A5 folds;
- four Raptor diagnostic views on explicit partial input scope;
- seven recovered CoAt-family predictions;
- fitted numerical fusion/calibration logic.

Full parent parity still depends on complete compatible acquisitions and legitimate evaluation membership.

## Failure-driven engineering

Recent stages hardened the pipeline around isolated image dependencies, numerical-parity checks, disk budgeting, deterministic checkpoint validation, resumable execution, sanitized access diagnostics, private destination verification, and regression tests for avoidable failures.

## Current scientific frontier

The strongest missing capability is **supervised anatomy-aware evidence routing**.

The controlled program focuses on:

- matched global-only residual control;
- explicit anatomical region pooling;
- visibility-aware auxiliary objectives;
- multi-plane localization consistency;
- multiple plausible localization hypotheses.

This direction complements the parent’s existing attention, medical pretraining, depth encoding, multi-plane fusion, and model diversity instead of duplicating them.

See [Anatomy-aware transfer program](ANATOMY_AWARE_TRANSFER_PROGRAM.md) and [Anatomy model qualification](ANATOMY_MODEL_QUALIFICATION.md).

## Publication philosophy

This repository is intentionally semi-reproducible.

Public: aggregate metrics/validation contracts, architecture narratives, experiment decisions, public-safe helpers/tests, CI publication checks, and notebook history.

Private: raw clinical/competition data, identifiers, row-level predictions, exact checkpoints/weights, source handles, orchestration packages/returns, and exact competition inference/submission implementation.
