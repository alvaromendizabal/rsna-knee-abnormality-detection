02 / INSPECT THE SPLIT

Select a fold to inspect its boundary.

What is actually being trained?

Twelve independent logistic outputs run full-batch gradient descent for 60 epochs per fold. Each fold fits normalization on its 384 training rows. Its 96 held-out rows are scored only after training. All rows from a scanner stay in one fold.

This generic implementation contains no private model weights or competition inference logic. The browser demo is separate from the Python demo and historical research.
