01 / Data science

Respect acquisition groups during validation.

Keep scanner groups disjoint and inspect aligned targets rather than relying on a random row split.

02 / Applied AI

Test cross-slice context as a controlled change.

Compare ordered context and image-model alternatives on a matched development population.

03 / ML engineering

Demonstrate checkpoint verification, corruption rejection, and completed-fold reuse in a small public pipeline.

04 / Data science

Keep score scope and inference validity separate.

Validate twelve-label metrics, row ordering, and uncertainty decisions without treating an integration fixture as clinical evidence.

A schema-valid prediction file does not establish an accurate or deployable model.

What the public evidence establishes.

The Python check verifies public source, retained notebook evidence, and research contracts. Optional Node tests execute the synthetic browser training pipeline. Historical MRI evaluation is separate; no clinical validity is established by these demonstrations.

MRI/DICOM images, patient or study identifiers, private prediction rows, trained weights, exact tuned inference recipes, and private GPU checkpoints remain excluded.

Headline signals are recorded project measurements, not results newly obtained by this review. Links point to the current default branch; the local receipt binds the exact reviewed file bytes with SHA-256. A checksum establishes consistency, not independent authentication of historical results.
